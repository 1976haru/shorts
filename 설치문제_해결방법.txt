ShortsMaker Studio v0.5.1 설치 문제 해결

1. 기존 폴더의 .venv 폴더가 있다면 삭제하거나 REPAIR.bat 실행
2. INSTALL.bat 실행
3. 설치가 끝나면 START.bat 실행

중요:
- INSTALL.bat / START.bat은 영문 ASCII 전용으로 제작되어
  Windows CMD 한글/UTF-8 깨짐 문제를 피합니다.
- Python 3.12 -> 3.11 -> 기타 Python 3 순서로 자동 탐지합니다.
- 기존 설치.bat / 실행.bat도 동일한 안전 버전으로 교체되어 있습니다.

권장:
- Python 3.11 또는 3.12
- Windows 10/11
