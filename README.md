# ShortsMaker Studio v0.5

## v0.5 핵심 업그레이드
- 기존 v0.4 기능 유지
- 이미지 1080×1920 자동 전처리
- Fill / Blur 방식 자동 변환
- 선택적 SRT 자막 삽입
- 채널별 업로드 메타데이터 자동 생성
  - 감성형
  - 시니어 올드팝
  - 일본 ChillRap
- 영상별 업로드정보 TXT 자동 생성
- 출력 폴더 ZIP 패키징
- 단일/배치 모두 적용
- 다크 UI / 파형 / TOP3 / 미리듣기 / 중지 / 재개형 처리 유지

## 중요
자막은 자동 음성인식이 아니라, 사용자가 준비한 SRT 파일을 선택하면 영상에 자동 삽입되는 방식입니다.
음악 채널 특성상 가사 정확도를 보존하기 위해 기본값은 '자막 없음'입니다.

## 추천 흐름
1. 음원 + 이미지
2. TOP3 분석
3. 필요시 SRT 선택
4. 숏츠 제작
5. 업로드정보 TXT 생성
6. ZIP 패키지 생성
